ตรวจพบภาษา: ไทย (ตัวอย่าง)
  • “ใบเสนอราคา” ใช้ quotation ซึ่งเป็นคำมาตรฐานในงานจัดซื้อ ถ้าเป็นงานบริการอาจใช้ proposal
  • คำลงท้าย “ค่ะ” ไม่มีคำตรงในภาษาอังกฤษ จึงใช้ please ให้สุภาพแทน
ติดตั้งเป็นแอปบนมือถือ
iPhone (Safari)
  1. เปิดลิงก์เว็บของแอปนี้ใน Safari
  2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. เลือก “เพิ่มไปยังหน้าจอโฮม” แล้วกด “เพิ่ม”
  4. เปิดแอปจากไอคอน แล้ววางคีย์ Gemini ในตั้งค่าอีกครั้ง (ไอคอนบนหน้าจอโฮมเก็บค่าแยกจาก Safari)
คอมพิวเตอร์ (Chrome / Edge)
  1. เปิดลิงก์เว็บของแอปนี้
  2. กดไอคอนติดตั้งท้ายช่องที่อยู่เว็บ หรือเมนู ⋮ → “ติดตั้งแอป”
  3. แอปจะอยู่ในเมนู Start เหมือนโปรแกรมทั่วไป

ปุ่ม “ถ่ายรูป” บนมือถือจะเปิดกล้องให้เลย ปุ่ม “ฟังเสียง” ใช้เสียงอ่านของเครื่อง ไม่เสียโควต้า
